اعلان توست در Svelte 5

Ding پکیجی دارد که مخصوص Svelte 5 ساخته شده است. وابستگی ندارد، به فایل CSS جدا نیاز ندارد و تابع toast هم در کامپوننت‌ها کار می‌کند و هم در ماژول‌های ساده.

امتحان کنید:

نصب

npm i @yusufceng1z/ding-svelte

فقط Svelte 5 را هدف گرفته است. اگر هنوز روی Svelte 4 هستید، این پکیج برایتان کار نمی‌کند.

افزودن به لی‌اوت ریشه

در SvelteKit این فایل src/routes/+layout.svelte است. در یک برنامهٔ Svelte ساده، از کامپوننت سطح بالای خودتان استفاده کنید.

<script>
        import { Toaster } from '@yusufceng1z/ding-svelte';
        let { children } = $props();
      </script>

      {@render children()}
      <Toaster position="top-center" theme="system" />

نمایش یک توست

import { toast } from '@yusufceng1z/ding-svelte';

      toast.success('Saved');
      toast.error('Payment failed', { description: 'Card declined' });

می‌توانید آن را از تابع load در +page.ts، از یک store، از یک کنترل‌کنندهٔ رویداد و از هر جای دیگری که در مرورگر اجرا می‌شود صدا بزنید. اگر روی سرور صدایش بزنید اتفاقی نمی‌افتد، چون صفحه‌ای برای نشان دادن آن وجود ندارد.

رفتارهایی که باید بدانید

همیشه فقط یک توست روی صفحه هست. فراخوانی تازه، به‌جای افزودن توست دوم، توست نمایان را با انیمیشن فنری به پیام جدید تبدیل می‌کند. این تفاوت اصلی با کتابخانه‌هایی است که توست‌ها را روی هم می‌چینند، مثل svelte-sonner، که در صفحهٔ جایگزین svelte-sonner مقایسه‌شان کرده‌ام.

خطاها، توست‌های در حال بارگذاری و توست‌هایی که دکمه دارند ماندگارند و تا وقتی بسته نشوند روی صفحه می‌مانند. بقیه بعد از پنج ثانیه بسته می‌شوند. برای حالت بارگذاری توست بارگذاری و برای دکمهٔ بازگردانی توست بازگردانی را ببینید.
