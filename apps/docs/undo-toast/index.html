چطور یک توست بازگردانی بسازیم

دیالوگ تأیید پیش از هر حذف، کاربران را کند می‌کند و آن‌ها در هر صورت از آن رد می‌شوند. انجام فوری کار و ارائهٔ «بازگردانی» در یک توست سریع‌تر است، و اگر بازگردانی واقعاً کار کند، امن‌تر هم هست.

امتحان کنید:

کد

import { toast } from '@yusufceng1z/ding-react';

      toast.success('Message deleted', {
        action: {
          label: 'Undo',
          onClick: () => {
            restore();
            return { type: 'info', title: 'Restored' };
          },
        },
      });

تابع کلیک می‌تواند یک شیء به‌روزرسانی (patch) برگرداند. در این صورت توست به‌جای بسته شدن، درجا به پیام «بازگردانی شد» تغییر می‌کند و کاربر تأیید می‌گیرد که بازگردانی انجام شده است. همین کد با @yusufceng1z/ding-svelte و @yusufceng1z/ding هم کار می‌کند، فقط ایمپورت فرق دارد.

بازگردانی را واقعی کنید

وقتی دکمه نشان داده می‌شود، آیتم را برای همیشه حذف نکنید. اول آن را حذف‌شده علامت بزنید و فقط بعد از گذشتن مهلت بازگردانی پاکش کنید، یا اگر سطل زباله دارید اصلاً پاکش نکنید. وگرنه «بازگردانی» وعده‌ای است که وقتی درخواست از قبل تمام شده نمی‌توانید به آن عمل کنید.

در Ding توستی که دکمه دارد تا وقتی بسته نشود می‌ماند، پس کسی با تایمر مسابقه نمی‌دهد. با این حال راه برگشت دومی هم نگه دارید، مثل صفحهٔ سطل زباله. توست را ساده می‌شود از دست داد و برای بعضی افراد دسترسی به آن سخت است؛ دسترس‌پذیری توست را ببینید.

برای اطلاعات بیشتر دربارهٔ اینکه توست چه زمانی ابزار درستی است: تجربهٔ کاربری اعلان توست.
