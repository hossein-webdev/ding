اعلان‌های توست در React

کتابخانهٔ توست Ding برای React، بدون وابستگی و بدون استایل‌شیت است. یک کامپوننت رندر می‌کنید و یک تابع را صدا می‌زنید. این صفحه راه‌اندازی و سؤال‌هایی را پوشش می‌دهد که معمولاً بعد از آن پیش می‌آید.

امتحان کنید:

نصب

فقط یک پکیج؛ چیز دیگری لازم نیست.

npm i @yusufceng1z/ding-react

رندر یک‌بارهٔ Toaster

آن را نزدیک ریشهٔ برنامه بگذارید. استایل‌ها از داخل جاوااسکریپت تزریق می‌شوند، پس نیازی به ایمپورت فایل CSS نیست.

import { Toaster } from '@yusufceng1z/ding-react';

      export default function App() {
        return (
          <>
            <Toaster position="top-center" theme="system" />
            {/* your app */}
          </>
        );
      }

صدا زدن toast از هر جا

خودِ toast یک تابع معمولی است، بنابراین در کنترل‌کننده‌های رویداد، افکت‌ها، کد دریافت داده و هر جای دیگری که کامپوننت نیست کار می‌کند.

import { toast } from '@yusufceng1z/ding-react';

      toast.success('Saved');
      toast.error('Payment failed', { description: 'Card declined' });

همیشه فقط یک توست روی صفحه است. اگر در حالی که یک توست نمایش داده می‌شود دوباره toast را صدا بزنید، توستِ روی صفحه به پیام جدید تبدیل می‌شود. اگر دو بار با همان پیام صدایش بزنید، به‌جای توست دوم یک شمارنده (×۲) اضافه می‌شود.

ذخیره‌سازی، بارگذاری و بازگردانی

برای یک درخواست، promise را بدهید تا همان یک توست از حالت بارگذاری به نتیجه برسد. جزئیات در صفحهٔ توست بارگذاری آمده است.

toast.promise(save(), {
        loading: 'Saving…',
        success: 'Saved',
        error: (err) => `Could not save: ${err.message}`,
      });

دکمهٔ اقدام می‌تواند یک شیء به‌روزرسانی (patch) برگرداند؛ توست‌های بازگردانی از همین راه تأیید می‌کنند که بازگردانی کار کرده است.

در Next.js و shadcn/ui

این پکیج با "use client" علامت‌گذاری شده است، پس در App Router در Next.js می‌توان Toaster را مستقیم در یک layout سمت سرور گذاشت. راه‌اندازی Next.js نشان می‌دهد چطور. اگر پروژه از shadcn/ui استفاده می‌کند، یک نصب با یک دستور هم وجود دارد.

زمان‌بندی

توست‌های ساده بعد از ۵ ثانیه بسته می‌شوند. توست‌های خطا و بارگذاری و توست‌هایی که دکمه دارند ماندگارند و تا وقتی کاربر آن‌ها را نبندد می‌مانند، چون کاربران نباید این‌ها را از دست بدهند. با قرار گرفتن ماوس روی توست یا فوکوس روی آن، تایمر متوقف می‌شود.

من Ding را نوشتم چون توستی می‌خواستم که روی هم نچیند. اگر این همان چیزی است که لازم دارید، ستاره‌ای در GitHub به دیگران کمک می‌کند آن را پیدا کنند.
