توستی برای shadcn/ui که با CLI اضافه می‌شود

کتابخانهٔ Ding یک registry item منتشر می‌کند، پس CLI مربوط به shadcn می‌تواند آن را مثل هر کامپوننت دیگری نصب کند.

امتحان کنید:

افزودن

npx shadcn@latest add @ding/ding

کتابخانهٔ Ding در دایرکتوری registry مربوط به shadcn فهرست شده است، پس فضای نام @ding بدون هیچ تنظیمی کار می‌کند. نشانی کامل هم جواب می‌دهد: npx shadcn@latest add https://ding.yusufcengiz.dev/r/ding.json.

این دستور @yusufceng1z/ding-react را نصب می‌کند و فایل components/ding-toaster.tsx را می‌نویسد. این فایل بسیار کوچک است: Toaster را با نام DingToaster دوباره export می‌کند، همراه با toast، و خودش را با "use client" علامت‌گذاری می‌کند تا در App Router در Next.js کار کند.

استفاده

import { DingToaster } from '@/components/ding-toaster';

      // once, in your root layout
      <DingToaster position="top-center" />
import { toast } from '@/components/ding-toaster';

      toast.success('Saved');
      toast.error('Payment failed', { description: 'Card declined' });

تفاوت آن با توست پیش‌فرض shadcn

این کتابخانه هر بار یک توست نشان می‌دهد و با فراخوانی بعدی آن را درجا تغییر شکل می‌دهد. استایل‌ها از جاوااسکریپت می‌آیند، پس به Tailwind وابسته نیست و CSS هم به پروژهٔ شما اضافه نمی‌کند. اگر لازم دارید چند توست هم‌زمان دیده شوند، توستی که shadcn عرضه می‌کند و توست‌ها را روی هم می‌چیند، انتخاب بهتری است.

از shadcn استفاده نمی‌کنید؟ همین پکیج همه‌جا کار می‌کند؛ اعلان‌های توست در React را ببینید.

پروژهٔ Ding را Yusuf Cengiz ساخته است. دارای مجوز MIT، کد منبع در GitHub.
