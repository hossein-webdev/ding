جایگزینی برای react-hot-toast

کتابخانهٔ react-hot-toast یک API کوچک و دوستانه دارد و Ding همین حس را حفظ کرده است. تفاوت در این است که Ding فقط یک توست روی صفحه نگه می‌دارد و آن را درجا تغییر شکل می‌دهد، ولی react-hot-toast چند توست را هم‌زمان نگه می‌دارد.

امتحان کنید:

همان نوع API

import { toast } from '@yusufceng1z/ding-react';

      toast.success('Saved');
      toast.error('Payment failed');
      toast.promise(save(), { loading: 'Saving…', success: 'Saved', error: 'Failed' });

کامپوننت <Toaster /> را همان‌طور که الان انجام می‌دهید، یک بار نزدیک ریشه رندر کنید.

چه چیزی عوض می‌شود

فراخوانی دوم توست دومی اضافه نمی‌کند؛ توستی که روی صفحه است به پیام جدید تبدیل می‌شود. می‌توانید خودتان هم با toast.update(id, patch) توست را به‌روزرسانی کنید، که ساختن نوار پیشرفت و کارهای چندمرحله‌ای را آسان می‌کند. اگر بخواهید، صدا هم در دسترس است (به‌طور پیش‌فرض خاموش).

برای کسانی که با بیش از یک استک کار می‌کنند، Ding یک پکیج Svelte 5 و یک پکیج بدون فریم‌ورک هم دارد.

نصب

npm i @yusufceng1z/ding-react

راه‌اندازی کامل در صفحهٔ توست React آمده است و مقایسه با یک جایگزین پشته‌ای در صفحهٔ Sonner.

پروژهٔ Ding را Yusuf Cengiz ساخته است. دارای مجوز MIT، کد منبع در GitHub.
