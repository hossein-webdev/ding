تازه‌های Ding 0.0.4

یک پکیج Vue، پشتیبانی از Next.js و CSP، و توست‌هایی آرام‌تر. بدون تغییرات ناسازگار با نسخه‌های قبل.

بیشتر تغییرات این نسخه از طرف کاربران Ding آمده است. دو رفع اشکال زیر نمونهٔ زنده دارند تا خودتان امتحانشان کنید.

npm i @yusufceng1z/ding@latest

Vue 3 و Nuxt جدید

پکیج تازه‌ای به نام @yusufceng1z/ding-vue اضافه شده است. پراپ‌هایش همان پراپ‌های نسخه‌های React و Svelte است: position، theme، labels و nonce.

npm i @yusufceng1z/ding-vue
<script setup>
import { Toaster, toast } from '@yusufceng1z/ding-vue';
</script>

<template>
  <Toaster position="top-center" theme="system" />
  <button @click="toast.success('Saved')">Save</button>
</template>

Toaster در جایی که می‌گذارید چیزی نمایش نمی‌دهد و بعد از بارگذاری صفحه شروع به کار می‌کند، پس رندر سمت سرور مشکلی ندارد. در Nuxt آن را در app.vue بگذارید و toast را از کد سمت کلاینت صدا بزنید، مثلاً از یک کنترل‌کنندهٔ کلیک. ما آن را در Vue با Vite و در Nuxt 4 آزموده‌ایم، هم در حالت توسعه و هم در بیلد نهایی.

این قابلیت را reslear در ایشوی ۷ خواسته بود.

Next.js بدون کامپوننت واسط

بیلد React حالا با "use client" شروع می‌شود. تا پیش از این، وارد کردن Toaster در یک لی‌اوت سمت سرور خطا می‌داد و باید یک کامپوننت کلاینتیِ خودتان را دورش می‌گذاشتید. دیگر لازم نیست.

// app/layout.tsx, a server component
import { Toaster } from '@yusufceng1z/ding-react';

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <Toaster />
        {children}
      </body>
    </html>
  );
}

toast را فقط در کامپوننت‌های کلاینتی صدا بزنید. راهنمای Next.js را ببینید.

پیشنهاد و پیاده‌سازی از Amidou Cissé است؛ پول‌ریکوئست ۱۰ را ببینید.

سازگار با CSP سخت‌گیرانه

Ding استایل‌هایش را در یک عنصر <style> می‌گذارد. اگر style-src شما استایل‌های درون‌خطی را مسدود می‌کند، nonce صفحهٔ خودتان را به آن بدهید. فقط همین عنصر به nonce نیاز دارد، چون مقدارهای مخصوص هر توست از راه DOM تنظیم می‌شود و CSP این را مجاز می‌داند.

<Toaster nonce={nonce} />     {/* React, Svelte */}
<Toaster :nonce="nonce" />    <!-- Vue -->

mountToaster({ nonce });        // plain DOM

پیشنهاد و پیاده‌سازی از Amidou Cissé است؛ پول‌ریکوئست ۱۱ را ببینید.

توست‌های پیشرفت دیگر سوسو نمی‌زنند رفع شد

وقتی توستی در حین اجرا متن خودش را عوض می‌کرد، مثل دانلودی که درصدش جلو می‌رود، انیمیشن متن در هر به‌روزرسانی دوباره پخش می‌شد و عنوان انگار می‌لرزید. حالا انیمیشن فقط وقتی پخش می‌شود که عنوان واقعاً چیز تازه‌ای شود، مثلاً «دانلود کامل شد».

وقتی عددها عوض می‌شوند، عنوان را زیر نظر بگیرید. باید تا آخر ثابت بماند.

MathiasWP این مشکل را در ایشوی ۵ گزارش داد. ضبط صفحهٔ IsaacHatilima هم در پیدا کردن علت کمک کرد.

دکمهٔ بستن همیشه آخر می‌ماند رفع شد

در رندرر DOM ساده، که Vue و Nuxt از آن استفاده می‌کنند، توست خطا یک دکمهٔ بستن دارد. اگر این توست بعداً به توستی با دکمهٔ اقدام، مثل «بازگردانی»، تبدیل می‌شد، دکمهٔ بستن پیش از دکمهٔ اقدام قرار می‌گرفت. حالا همیشه در انتها می‌ماند. React و Svelte این مشکل را نداشتند.

خطا را باز کنید و بعد «بازگردانی» را بزنید. ترتیب دکمه‌ها باید این باشد: بازگردانی، بستن.
