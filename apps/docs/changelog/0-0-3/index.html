What's new in Ding 0.0.3

Accessibility and polish. No breaking changes.

Translate the screen reader labels New

Two names were hard-coded in English: the notifications region and the close button. On a page in another language, a screen reader read the toast in that language and these two controls in English. Now you pass your own strings. Keys you leave out keep the English default.

toast.configure({
  labels: { region: 'Bildirimler', dismiss: 'Bildirimi kapat' },
});

React and Svelte take the same thing as a prop: <Toaster labels={{ dismiss: 'Fermer' }} />. Plain DOM takes it in mountToaster({ labels }).

These names are invisible on the page, only a screen reader says them. Pick a language to see what it would read.

Bigger click areas

Buttons keep their look but the area that counts as a click grew from 30 to 44 pixels tall, so a thumb that lands slightly above or below still hits. Neighbouring buttons never overlap.

Alt + T reaches every toast

Alt + T moves focus into the toast, which also pauses its timer. Before, it only worked when the toast had a button. A plain "Saved" toast could not be reached by keyboard and disappeared after five seconds. Now focus lands on the toast itself, with a ring inside it.

Open the toast, then press Alt + T within five seconds. It only works in the After mode, because the old code is gone.

Esc no longer closes toasts behind your back

Esc dismisses toasts, but it used to do that even while you pressed Esc to close a dialog, a menu or to clear a text field. Now it leaves the toast alone when focus is in one of those. Press Esc anywhere else and it still dismisses.

Smaller fixes

  • Centered icon. The status icon sat one pixel low next to the text. It is now centered in the pill.
  • Even padding. A toast without buttons had about 29 pixels of space after the text and 12 before the icon. The right side is now about 15, so the pill looks balanced.
  • Safari drag. Dragging a toast no longer highlights its text in Safari.
  • Page styles can't push buttons around. A site-wide button { margin } rule used to shift the close button. The toast now resets its own button margins.

For contributors

A fresh clone now installs, type-checks, tests and builds, and a GitHub Actions workflow runs the same steps on every pull request. Running the tests needs Node 22.18 or newer. The packages themselves still support Node 18 and up. Thanks to Amidou Cissé for pull request 1.
