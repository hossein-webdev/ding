هر تغییر زیر یک نمونهٔ زنده دارد. بین قبل و بعد جابه‌جا شوید تا تفاوت را حس کنید.

npm i @yusufceng1z/ding@latest
مقایسه:

ترجمهٔ برچسب‌های صفحه‌خوان جدید

دو نام در کد به انگلیسی ثابت شده بود: ناحیهٔ اعلان‌ها و دکمهٔ بستن. در صفحه‌ای به زبان دیگر، صفحه‌خوان خودِ توست را به همان زبان می‌خواند، ولی این دو کنترل را به انگلیسی. حالا رشته‌های خودتان را می‌دهید. کلیدهایی که نگذارید همان پیش‌فرض انگلیسی را نگه می‌دارند.

toast.configure({
  labels: { region: 'Bildirimler', dismiss: 'Bildirimi kapat' },
});

React و Svelte همین را به‌صورت پراپ می‌گیرند: <Toaster labels={{ dismiss: 'Fermer' }} />. DOM ساده آن را در mountToaster({ labels }) می‌گیرد.

این نام‌ها روی صفحه دیده نمی‌شوند و فقط صفحه‌خوان آن‌ها را می‌گوید. یک زبان انتخاب کنید تا ببینید صفحه‌خوان چه می‌خواند.

region:  -
close:   -

پیشنهاد و پیاده‌سازی از Amidou Cissé است؛ پول‌ریکوئست ۳ را ببینید.

ناحیهٔ کلیک بزرگ‌تر

ظاهر دکمه‌ها همان است، اما ناحیه‌ای که کلیک حساب می‌شود از ۳۰ به ۴۴ پیکسل ارتفاع رسیده است. پس انگشتی که کمی بالاتر یا پایین‌تر بنشیند هم به دکمه می‌خورد. دکمه‌های کنار هم هیچ‌وقت روی هم نمی‌افتند.

ناحیه‌های کلیک را نشان دهید، توست را باز کنید و بعد درست بالا یا پایین «تلاش دوباره» کلیک کنید.

هنوز کلیکی نشده است

Alt + T به همهٔ توست‌ها می‌رسد

Alt + T فوکوس را به توست می‌برد و زمان‌سنج آن را هم متوقف می‌کند. قبلاً فقط وقتی کار می‌کرد که توست دکمه داشت. یک توست ساده مثل «ذخیره شد» با صفحه‌کلید در دسترس نبود و بعد از پنج ثانیه ناپدید می‌شد. حالا فوکوس روی خودِ توست می‌نشیند و یک حلقهٔ فوکوس داخل آن دیده می‌شود.

توست را باز کنید و ظرف پنج ثانیه Alt + T را بزنید. فقط در حالت بعد کار می‌کند، چون کد قدیمی دیگر وجود ندارد.

فوکوس: روی توست نیست

Esc دیگر ناخواسته توست‌ها را نمی‌بندد

Esc توست‌ها را می‌بندد، اما قبلاً حتی وقتی Esc را برای بستن یک دیالوگ یا منو یا پاک کردن یک فیلد متنی می‌زدید هم همین کار را می‌کرد. حالا اگر فوکوس روی یکی از این‌ها باشد، کاری به توست ندارد. در هر جای دیگر Esc بزنید، باز هم توست بسته می‌شود.

یک توست ماندگار باز کنید. داخل فیلد کلیک کنید یا دیالوگ را باز کنید، بعد Esc بزنید.

اصلاحات کوچک‌تر

  • آیکون هم‌تراز. آیکون وضعیت یک پیکسل پایین‌تر از متن می‌نشست. حالا در کپسول دقیقاً وسط است.
  • فاصلهٔ درونی یکنواخت. توستی بدون دکمه حدود ۲۹ پیکسل بعد از متن و ۱۲ پیکسل قبل از آیکون فاصله داشت. حالا فاصلهٔ بعد از متن حدود ۱۵ است و کپسول متعادل‌تر دیده می‌شود.
  • کشیدن در Safari. کشیدن توست دیگر متن آن را در Safari انتخاب نمی‌کند.
  • استایل‌های صفحه دکمه‌ها را جابه‌جا نمی‌کنند. قاعده‌ای سراسری مثل button { margin } قبلاً دکمهٔ بستن را جابه‌جا می‌کرد. حالا توست حاشیهٔ دکمه‌های خودش را بازنشانی می‌کند.

برای مشارکت‌کنندگان

نصب، بررسی نوع‌ها، تست و بیلد روی یک کلون تازه حالا بی‌مشکل انجام می‌شود و یک workflow در GitHub Actions همین مراحل را روی هر پول‌ریکوئست اجرا می‌کند. برای اجرای تست‌ها به Node 22.18 یا جدیدتر نیاز است، ولی خود پکیج‌ها همچنان از Node 18 به بالا پشتیبانی می‌کنند. از Amidou Cissé برای پول‌ریکوئست ۱ سپاسگزاریم.
