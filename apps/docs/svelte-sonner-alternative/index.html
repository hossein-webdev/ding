جایگزینی برای svelte-sonner در Svelte 5

svelte-sonner نسخهٔ Svelte از Sonner است و توست‌ها را روی هم می‌چیند. Ding کتابخانه‌ای جداست که حول یک توست روی صفحه ساخته شده و با رسیدن پیام تازه، همان توست درجا تغییر شکل می‌دهد.

امتحان کنید:

نصب و افزودن به برنامه

npm i @yusufceng1z/ding-svelte
<script>
        import { Toaster } from '@yusufceng1z/ding-svelte';
        let { children } = $props();
      </script>

      {@render children()}
      <Toaster position="top-center" theme="system" />

استفاده

import { toast } from '@yusufceng1z/ding-svelte';

      toast.success('Saved');
      toast.promise(save(), { loading: 'Saving…', success: 'Saved', error: 'Failed' });

آیا باید مهاجرت کنید؟

اگر هر بار یک پیام می‌خواهید و وابستگی نمی‌خواهید، بله، ارزش امتحان کردن دارد. اگر لازم است چند توست هم‌زمان روی صفحه باشند، سراغ کتابخانه‌ای بروید که توست‌ها را روی هم می‌چیند. Ding فقط از Svelte 5 پشتیبانی می‌کند.

راه‌اندازی کامل Svelte در صفحهٔ توست Svelte آمده است و دلیل انتخاب «هر بار یک توست» در صفحهٔ جایگزین Sonner توضیح داده شده.
