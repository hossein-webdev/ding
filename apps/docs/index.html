توست‌هایی با فیزیک فنری واقعی.

Ding یک کتابخانهٔ توست (اعلان کوتاه) است. در هر لحظه فقط یک توست روی صفحه دیده می‌شود و فراخوانی تازه، به‌جای روی هم چیدن، آن را درجا تغییر شکل می‌دهد. بدون وابستگی و با مجوز MIT. با React، Svelte 5، Vue 3 و جاوااسکریپت ساده کار می‌کند.

نصب

  • React: npm i @yusufceng1z/ding-react
  • Svelte 5: npm i @yusufceng1z/ding-svelte
  • Vue 3 و Nuxt: npm i @yusufceng1z/ding-vue
  • جاوااسکریپت ساده: npm i @yusufceng1z/ding
  • رجیستری shadcn/ui: npx shadcn@latest add @ding/ding
