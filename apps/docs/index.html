Toasts with real spring physics.

Ding is a toast notification library. Only one toast is on screen at a time, and a new call morphs it in place instead of stacking. No dependencies, MIT licensed. Works with React, Svelte 5, Vue 3 and plain JavaScript.

Install

  • React: npm i @yusufceng1z/ding-react
  • Svelte 5: npm i @yusufceng1z/ding-svelte
  • Vue 3 and Nuxt: npm i @yusufceng1z/ding-vue
  • Plain JavaScript: npm i @yusufceng1z/ding
  • shadcn/ui registry: npx shadcn@latest add @ding/ding
