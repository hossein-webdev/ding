اعلان‌های توست در Next.js

این پکیج با "use client" علامت‌گذاری شده است، پس Toaster مستقیم در layout ریشهٔ شما قرار می‌گیرد. تنها قاعده این است: toast را از کد سمت کلاینت صدا بزنید. بقیهٔ کار مثل React ساده است.

امتحان کنید:

نصب

npm i @yusufceng1z/ding-react

افزودن Toaster به layout

آن را فقط یک بار در app/layout.tsx رندر کنید. layout همچنان یک server component می‌ماند و به فایل wrapper نیازی نیست.

import { Toaster } from '@yusufceng1z/ding-react';

      export default function RootLayout({ children }: { children: React.ReactNode }) {
        return (
          <html lang="en">
            <body>
              {children}
              <Toaster position="top-center" theme="system" />
            </body>
          </html>
        );
      }

صدا زدن toast از کد کلاینت

"use client";

      import { toast } from '@yusufceng1z/ding-react';

      export function SaveButton() {
        return <button onClick={() => toast.success('Saved')}>Save</button>;
      }

اکشن‌های سرور (Server Actions)

تابع toast در مرورگر اجرا می‌شود، پس نمی‌توان آن را داخل یک server action صدا زد. آن را از کد سمت کلاینتی که اکشن را فعال می‌کند صدا بزنید و promise مربوط به اکشن را به آن بدهید:

toast.promise(saveAction(formData), {
        loading: 'Saving…',
        success: 'Saved',
        error: 'Could not save',
      });

اگر از Pages Router استفاده می‌کنید، <Toaster /> را در pages/_app.tsx رندر کنید. اگر پروژه از shadcn/ui استفاده می‌کند، نصب shadcn هم جواب می‌دهد. برای بخش‌هایی که به Next ربطی ندارند، اعلان‌های توست در React را ببینید.
