Next.js toast notifications

The package is marked "use client", so the Toaster goes straight into your root layout. The one rule: call toast from client code. Everything else is the same as plain React.

Try it:

Install

npm i @yusufceng1z/ding-react

Add the Toaster to the layout

Render it once in app/layout.tsx. The layout stays a server component, no wrapper file needed.

import { Toaster } from '@yusufceng1z/ding-react';

      export default function RootLayout({ children }: { children: React.ReactNode }) {
        return (
          <html lang="en">
            <body>
              {children}
              <Toaster position="top-center" theme="system" />
            </body>
          </html>
        );
      }

Call toast from client code

"use client";

      import { toast } from '@yusufceng1z/ding-react';

      export function SaveButton() {
        return <button onClick={() => toast.success('Saved')}>Save</button>;
      }

Server actions

toast runs in the browser, so it cannot be called inside a server action. Call it from the client code that triggers the action and pass the action's promise:

toast.promise(saveAction(formData), {
        loading: 'Saving…',
        success: 'Saved',
        error: 'Could not save',
      });

With the Pages Router, render <Toaster /> in pages/_app.tsx. If the project uses shadcn/ui, the shadcn install also works. For the non-Next parts see React toast notifications.
