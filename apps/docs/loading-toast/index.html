توست‌های بارگذاری: از «در حال ذخیره…» تا «ذخیره شد»

توست بارگذاری می‌گوید کاری شروع شده و بعد خودش به نتیجه تبدیل می‌شود. وقتی فقط یک توست روی صفحه است، پیام در همان جا از «در حال ذخیره…» به «ذخیره شد» تغییر می‌کند، نه اینکه توست دومی کنارش ظاهر شود.

امتحان کنید:

سپردن promise به توست

این کوتاه‌ترین روش است: یک promise و سه پیام را بدهید.

import { toast } from '@yusufceng1z/ding-react';

      toast.promise(save(), {
        loading: 'Saving…',
        success: 'Saved',
        error: (err) => `Could not save: ${err.message}`,
      });

به‌روزرسانی دستی

برای آپلودها و کارهای مرحله‌دار دیگر، شناسه را نگه دارید و توست را در حین کار به‌روزرسانی کنید. مقدار progress از ۰ تا ۱ است و نواری باریک در پایین توست نشان می‌دهد.

const id = toast.loading('Uploading photo…', { progress: 0 });
      toast.update(id, { progress: 0.6 });
      toast.update(id, { type: 'success', title: 'Photo uploaded', progress: null });

نکته‌های مهم

توست بارگذاری تا وقتی آن را به‌روزرسانی نکنید یا نبندید روی صفحه می‌ماند، پس مطمئن شوید هر مسیر کد به یکی از این دو ختم می‌شود. فقط جدیدترین فراخواننده می‌تواند توستِ مشترک را به‌روزرسانی کند. اگر درخواستی کند باشد و بعد از نمایش پیام جدیدتر تمام شود، به‌روزرسانی‌اش نادیده گرفته می‌شود و پیام جدیدتر را بازنویسی نمی‌کند.

برای کارهایی که چند دقیقه طول می‌کشند، پیشرفت را روی خود صفحه هم نشان بدهید. توست جای مناسبی برای وضعیت کارهای طولانی نیست. برای اینکه بدانید کی از کدام استفاده کنید، تجربهٔ کاربری (UX) اعلان‌های توست را ببینید.
