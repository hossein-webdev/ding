Ding مستندات GitHub

اعلان‌های توست در جاوااسکریپت بدون فریم‌ورک

هستهٔ Ding به React یا Svelte نیازی ندارد. اگر یک صفحهٔ جاوااسکریپت ساده، یک برنامهٔ Vue یا هر پروژهٔ دیگری دارید، می‌توانید مستقیم از پکیج هسته استفاده کنید.

امتحان کنید:

نصب

npm i @yusufceng1z/ding

راه‌اندازی و نمایش

import { mountToaster, toast } from '@yusufceng1z/ding';

      const unmount = mountToaster({ position: 'top-center' });

      toast.success('Saved');
      toast.error('Payment failed', { description: 'Card declined' });

تابع mountToaster تابعی برمی‌گرداند که Toaster را دوباره حذف می‌کند؛ این کار وقتی به درد می‌خورد که صفحه از بین می‌رود یا Toaster باید فقط روی بعضی مسیرها وجود داشته باشد.

به‌روزرسانی یک کار طولانی

تابع toast.loading یک شناسه برمی‌گرداند. آن را به toast.update بدهید تا همان توست مراحل پیشرفت را طی کند و به نتیجه برسد.

const id = toast.loading('Uploading photo…', { progress: 0 });
      toast.update(id, { progress: 0.6 });
      toast.update(id, { type: 'success', title: 'Photo uploaded', progress: null });

گزینه‌ها

جایگاه و پوسته روی mountToaster تنظیم می‌شوند یا بعداً با toast.configure({ position, theme }). فهرست کامل گزینه‌ها در مستندات آمده است.

اگر از React یا Svelte استفاده می‌کنید، پکیج‌های مخصوص هر فریم‌ورک فقط یک لایهٔ نازک روی همین پکیج هستند. به React یا Svelte سر بزنید. کد در GitHub است.
